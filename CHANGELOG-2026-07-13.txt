- **File:** `src/services/subscription.service.js` — `checkAccess()`

- **File:** `src/controllers/payment.controller.js`, `src/controllers/sandbox.controller.js`

## 5. Budget: Fix Duplicate Data + Per Hari / Per Bulan
- **File:** `src/services/budget.service.js` (full rewrite of relevant parts)
  - **Bug fix:** AES-256-GCM non-deterministic → `findFirst` dengan encrypted value tidak pernah match
  - Solusi: `findExistingBudget()` decrypt semua budget user dan bandingkan dalam plaintext
  - **Fitur baru:** Budget per hari / per minggu / per bulan
    - `getCurrentPeriodKey(period)` — return `YYYY-MM-DD` (hari), `YYYY-MM-DD` (Senin) untuk minggu, `YYYY-MM` (bulan)
    - `setBudget(userId, category, amount, period)` — parameter period baru
    - `checkBudget()` — tampilkan budget harian dan bulanan terpisah
    - `parsePeriod(input)` — deteksi alias: per hari, harian, /hari, per bulan, bulanan, dll
- **File:** `src/services/message.handler.js`
  - Literal handler `set budget`: parse alias period dari input
  - AI intent handler `set_budget`: parse alias period dari input
  - Contoh command: `set budget makanan 50000 per hari`, `set transport 200000 /bulan`
